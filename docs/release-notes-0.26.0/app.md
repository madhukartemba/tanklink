## Changes

- When the pump removes a tank sensor because its tank went into pairing mode, the app shows a notice on the home screen ("Tank sensor 3F2A was removed. Its tank went into pairing mode, so the pump dropped it. Pair it again if this wasn't you."), and sends a notification if the app is closed (Alerts, Android 12 and later). There is a new "Tank sensor removed" switch under Settings → Alerts.

Goes with pump 0.26.0 (and tank 0.5.0 on the tank).
