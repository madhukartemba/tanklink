## Changes

- New starter option: **Single-phase MCB starter** (relay 1 stays on while the pump runs). Needs pump 0.28.0.
- The starter type can't be changed while the pump is running.
- Error messages are short and plain instead of long technical text that could fill the screen.
- Changing a setting while the pump isn't connected now says so, instead of looking saved.
- A pump whose Bluetooth address changed no longer shows up twice.

Goes with pump 0.28.0 and tank 0.6.0.
