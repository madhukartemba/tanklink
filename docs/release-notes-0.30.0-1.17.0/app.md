## Changes

- Connects to the pump faster, especially away from home.
- Moves from Bluetooth to Wi-Fi without dropping the screen.
- "Fill when low" can be turned on for a tank with only its full float.
- A warning when one pump fills several tanks: auto-fill only fills the selected tank, so the valve or lever must point at it.

Goes with pump 0.30.0 and tank 0.7.1 (unchanged). Update the pump and the app together to use "Fill when low" with one float.
