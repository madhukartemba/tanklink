## Changes

- Settings → Wi-Fi → Pump updates shows what the pump found and when it last looked ("Up to date · checked 3 h ago", "Version 0.24.0 is ready"), with an Update button when one is waiting.
- "Check now" waits for the pump's answer and tells you: up to date, available, no internet, or failed. It says so if the pump is running or busy.
- The update sheet lists what is new in the release.
- The "pump is updating" banner shows progress using the size the pump reports, even for an update this phone didn't start.
- Cleanups: the app no longer accepts shorter, older-format data from the pump, and connection errors for Wi-Fi, update status and alerts are shown instead of ignored.

Goes with pump 0.24.0. Update both.
