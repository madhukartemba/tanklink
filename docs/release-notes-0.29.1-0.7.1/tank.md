## Changes

- The radio link to the pump now sends at 10 mW, the legal limit for 433 MHz. The more robust radio setting from 0.7.0 stays, so range is still a bit better than before 0.7.0.
- Lower battery use while sending than 0.7.0.

Works with pump 0.29.0 and 0.29.1, so they don't have to be updated together this time. Goes with pump 0.29.1 and app 1.16.0 (unchanged). Nothing to pair or set again.
