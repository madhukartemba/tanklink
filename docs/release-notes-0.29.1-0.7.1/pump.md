## Changes

- The radio link to the tank now sends at 10 mW, the legal limit for 433 MHz. The more robust radio setting from 0.29.0 stays, so range is still a bit better than before 0.29.0.

Works with tank 0.7.0 and 0.7.1, so they don't have to be updated together this time. Goes with tank 0.7.1 and app 1.16.0 (unchanged). Nothing to pair or set again.
