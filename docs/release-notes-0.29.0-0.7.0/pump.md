## Changes

- Much longer range to the tank sensor: the radio now uses a slower, more robust setting and full transmit power. Expect roughly 2–4 times the distance, depending on walls and trees.

**Update the pump and the tank together.** Pump 0.29.0 and tank 0.7.0 use the new radio setting and can't hear older versions at all. Update the pump first, then the tank (over Bluetooth from the app; it doesn't need the pump for that). Pairing is kept: nothing to pair or set again.

Goes with tank 0.7.0 and app 1.16.0 (unchanged).
