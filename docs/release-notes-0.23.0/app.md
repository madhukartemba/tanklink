## Changes

- The app knows when the pump is updating, whoever started it (the pump itself, another phone, or this phone). The home screen shows "Pump is updating itself" with progress, the Start slider reads "Updating…", and Add another phone, Sign out other phones, Factory reset, Wi-Fi changes and the update buttons are paused until it finishes.
- No "pump update available" banner while the pump is updating.
- Alerts, Wi-Fi and update wording and fixes from the last releases stay as they were.

Goes with pump 0.23.0.
