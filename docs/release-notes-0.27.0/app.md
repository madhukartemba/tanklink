## Changes

- Renaming a pump now stores the name on the pump itself, so every phone shows the same name. Other phones get the new name when they connect, or straight away if they are connected. Renaming needs the pump connected, because the name is kept on the pump; the dialog says so if it isn't.
- Names can be up to 24 characters.

Goes with pump 0.27.0. Update both. Names saved on a phone before are not copied to the pump: rename the pump once from any phone to share its name.
