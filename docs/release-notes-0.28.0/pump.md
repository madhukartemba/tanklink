## Changes

- New starter type: **single-phase MCB**. Relay 1 stays closed while the pump runs and opens when it stops; relay 2 is not used. A restart or power cut always opens it, so the pump stays off until started again.
- The starter type can't be changed while the pump is running.
- Holding the button now starts the light bloom right away and fills smoothly; starting the pump needs a 1-second hold.
- A firmware update erases the old one bit by bit as it arrives, so the pump keeps answering during an update.
- A phone that sends update data during another phone's update no longer cancels it.
- Factory reset now clears everything the pump saved, in one go.
- Uses less memory, and fixes a few rare crashes and lock-ups in Wi-Fi and updates.

Goes with app 1.15.1 or later; the single-phase option is in the next app release. Tank 0.5.1 is unchanged. No layout change: nothing to pair or set again.
