## Changes

- Stronger radio link to the tank: it now sends at 50 mW (was 10 mW), for more range and fewer missed tank updates, especially with an external antenna.
- Fewer false receptions from radio noise while the pump listens for the tank.
- The tank's signal strength in the app is more accurate when the signal is weak. Strong signals read a few dB higher than before.

Goes with tank 0.8.1 and app 1.21.0 (unchanged). Works with tank 0.8.0 too, so they don't have to be updated together, but update both for the best range. Nothing to pair or set again.
