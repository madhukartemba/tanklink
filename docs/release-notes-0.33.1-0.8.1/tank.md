## Changes

- Stronger radio link to the pump: it now sends at 50 mW (was 10 mW), for more range and fewer missed updates, especially with an external antenna. Battery use per update goes up a little.

Goes with pump 0.33.1 and app 1.21.0 (unchanged). Works with pump 0.33.0 too, so they don't have to be updated together, but update both for the best range. Nothing to pair or set again.
