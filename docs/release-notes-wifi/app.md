## Changes

- Wi-Fi for the pump: set it up from Settings → Wi-Fi, and the app then connects over Wi-Fi when the pump is reachable and over Bluetooth otherwise ("Connect over" can force Bluetooth).
- Pump updates: let the pump download the update itself, send it from the phone over Wi-Fi, or send it over Bluetooth, with "Try over Bluetooth" if one fails.
- The home screen shows "Pump update available" when the pump finds one itself, and Settings → Wi-Fi can install updates automatically when the pump is idle.

Goes with pump 0.21.0. Update both. Tank updates and adding a phone or pump still use Bluetooth.
