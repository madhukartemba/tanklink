## Changes

- "Install pump updates automatically" is now on by default for a new or factory-reset pump. It does nothing until the pump has Wi-Fi, and then only installs when the pump is idle and no fill is due soon. A pump that is already set up keeps its current setting; turn it on in the app's Wi-Fi settings if you want it.

Goes with app 1.16.0 and tank 0.6.0 (unchanged). No layout change: nothing to pair or set again.
