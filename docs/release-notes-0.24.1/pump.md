## Changes

- Starting the pump with its button is quicker: hold for about half a second (it was one second), then let go. Stopping a running pump is still a single press. Holding for 5 seconds for pairing and 10 more for a factory reset are unchanged.

Goes with app 1.13.1 (the app is unchanged in how it talks to the pump, so either order works). No protocol change, nothing to pair again, no wiring change.
